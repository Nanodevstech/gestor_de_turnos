# 📋 Gestor de Turnos

Sistema desarrollado para la administración, reserva y gestión eficiente de turnos.

## 🚀 Tecnologías utilizadas
- Python
- SQL / Base de Datos
- Git & GitHub

## ⚙️ Funcionalidades principales
- Registro y asignación de turnos.
- Consulta y filtrado de disponibilidad.
- Gestión persistente de datos.
